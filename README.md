# Rota Certa Impressora

Este repositório guarda as versões instaláveis do aplicativo Android auxiliar do Rota Certa. O aplicativo recebe comandas pelo serviço de impressão do Android, imprime em uma térmica Bluetooth ESC/POS de 80 mm e importa entregas próprias do iFood para a conta da loja.

Baixe o APK mais recente na seção [Releases](https://github.com/DesMortel/rota-certa-printer-releases/releases). A primeira versão é experimental: confirme no seu aparelho se o iFood oferece **Rota Certa Impressora** no seletor de impressão e teste impressão e corte antes de depender da importação na operação da loja.

O código-fonte fica em um projeto separado deste repositório. Para atualizar o aplicativo, instale o APK novo sobre o anterior, mantendo a mesma assinatura.
